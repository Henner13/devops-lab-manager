# DevOps Lab Manager

Laboratorio DevOps basado en Docker, SSH, Ansible y GitHub Actions.

## Tecnologías

- Docker
- Docker Compose
- Python
- Ansible
- GitHub Actions
- Prometheus
- Grafana

## Objetivos

- Automatizar la gestión de servidores
- Implementar CI/CD
- Practicar Infraestructura como Código
- Desarrollar herramientas DevOps propias
